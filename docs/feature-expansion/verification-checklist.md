| 1.7 | **重复导入检测** | 1. 导入一个 `.md` 文件 2. 再次导入同一个文件（相同文件路径/相同文件内容） | 第二次导入被跳过，不创建重复书条。桌面/移动均提示或静默跳过。 | | | Task 6：通过 `fileHash` 去重 |

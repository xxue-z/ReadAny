# ReadAny 功能扩展方案

在现有阅读器基础上新增三大能力：**文档创建与编辑**、**跨格式笔记系统**、**AI 测验模块**。分三个阶段增量交付，每阶段可独立上线。

| Phase | 文档 | 内容 |
|---|---|---|
| Phase 1 | [01-doc-edit-tags.md](./01-doc-edit-tags.md) | Markdown 导入、文档编辑器、标签/分组管理 |
| Phase 2 | [02-cross-format-notes.md](./02-cross-format-notes.md) | PDF 高亮与笔记、全格式笔记覆盖 |
| Phase 3 | [03-ai-quiz.md](./03-ai-quiz.md) | AI 测验生成、题库、自定义测验、报告 |
